Política de Privacidade

Gestor de Projetos — Eco Digital · Atualizado em 21/10/2026

O Gestor de Projetos é um sistema de gestão de projetos, tarefas e finanças da Eco Digital. Esta página explica como tratamos os dados, inclusive os do Google Drive quando você conecta sua conta.

Quais dados do Google acessamos

Ao conectar o Google Drive, o sistema pede somente a permissão drive.file. Ela dá acesso apenas aos arquivos e pastas que o próprio Gestor de Projetos cria ou que você envia por ele. O sistema não consegue ver, listar nem alterar os demais arquivos do seu Drive. Também lemos o seu endereço de e-mail para mostrar qual conta está conectada.

Como usamos esses dados

Usamos o acesso exclusivamente para guardar os anexos de projetos e tarefas no seu Drive e para exibi-los dentro do sistema para quem tem permissão no projeto. Não usamos esses dados para publicidade, não os vendemos e não os compartilhamos com terceiros.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e segurança

A credencial de acesso é guardada de forma restrita no servidor (Supabase), sem acesso pelo navegador. Os arquivos ficam no seu Google Drive e o acesso a eles dentro do sistema respeita as permissões de cada projeto.

Como remover o acesso

Você pode desconectar o Drive a qualquer momento em Configurações → Google Drive, ou revogar o acesso em myaccount.google.com/permissions. Ao desconectar, o sistema apaga a credencial; os arquivos continuam no seu Drive.
